# Material scout

The material scout pages of a private game project, published as a static site (GitHub Pages).

Everything here is generated by the game repo's `tools/publish_scout.sh` and replaced on every run: do not edit by hand.

Pictures: ambientCG previews (CC0 1.0) and the game's own code-drawn textures (or copies of CC0 library textures). Poly Haven's site previews are not included.
